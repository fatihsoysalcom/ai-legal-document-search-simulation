# AI Legal Document Search Simulation

This Python script simulates a simplified AI-powered search system for legal documents. It demonstrates how an AI model might help legal professionals quickly find relevant information within a large corpus of complex texts, addressing challenges like language barriers and the volume of legal data, as discussed in the article about OpenThai 2.0 Legal.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python3 main.py`
